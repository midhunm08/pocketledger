KODIAK Borrowing Cost Engine — Starter Version
================================================

FILES
- index.html: application structure
- styles.css: visual styling
- app.js: input handling and illustrative calculations

HOW TO RUN
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, Firefox or another modern browser.
3. No installation, server, internet connection or account is required.

IMPORTANT
This is an educational prototype, not a statutory computation tool.
The calculation model is intentionally simplified:
- General borrowing balances are treated as constant for the year.
- It does not yet model date-wise drawdowns, repayments or daily/monthly interest.
- It does not yet implement the full Ind AS commencement, suspension, cessation and cap tests.
- ICDS average asset costs are entered manually; prescribed asset-by-asset averages are not yet automated.
- Specific borrowing and temporary investment income treatment must be validated against the applicable notified text and facts.

The next development stage should add:
1. Loan master with dated drawdowns, repayments and actual interest.
2. CWIP/PPE/inventory asset register with dated additions and put-to-use/completion dates.
3. Fund utilisation mapping and specific/general borrowing traceability.
4. Full Ind AS 23 and ICDS IX rules, asset-wise calculations and audit trail.
5. Excel import/export, reconciliation and audit exception reports.

Use current authoritative versions of Ind AS 23, ICDS IX, the Income-tax Act/Rules and applicable guidance before relying on any computation.
